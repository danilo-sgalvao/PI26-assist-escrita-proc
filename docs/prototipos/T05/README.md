# Protótipo de baixa fidelidade — T05 (#9)

- **Versão:** 0.1
- **Data:** 11/11/2026
- **Autor:** Enzo Machado, com apoio de IA (Codex)
- **Revisor:** área A, pendente
- **Estado:** proposta para revisão

Abra [index.html](index.html) no navegador. O menu e os links entre seções permitem percorrer os fluxos sem backend. O protótipo usa dados ilustrativos; controles de formulário e ações não persistem dados.

| Tela | Requisitos rastreados | Fluxo principal |
|---|---|---|
| Termo de ciência | RF21, RF22, RN10 | Ler o registro e o uso dos dados; seguir para atividades |
| Atividades | RF01, RF02, RF16, RF22 | Iniciar uma produção vinculada à atividade |
| Editor por etapas | RF03, RF04, RF17, RF18, RF14 | Planejar, avançar ou voltar, consultar versões e pedir apoio |
| Histórico e comparação | RF04, RF05, RF06, RF18 | Filtrar versões e escolher duas para comparação |
| Painel de apoio | RF07–RF10, RF12, RN01, RN02 | Formular dúvida sobre a escrita; receber orientação |
| Painel do professor | RF05, RF06, RF10–RF13, RF15, RF18, RN05, RN06 | Consultar o processo de uma atividade e de cada estudante |
| Meus registros | RF04, RF05, RF10–RF12, RF18, RF20, RN10 | Consultar os próprios dados e indicadores |
